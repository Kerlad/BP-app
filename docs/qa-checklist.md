# Ручная проверка перед релизом: доступность и экраны

Чек-лист из [10.6](10-testing.md#106-доступность). Автоматика (JVM) уже проверяет на каждом снимке экрана:
у каждого нажимаемого элемента есть имя и цель нажатия не меньше 48 × 48 dp
(`assertAccessible()` в `:core:ui`, `testFixtures`). Проверки Compose для устройства
(`enableAccessibilityChecks`) на JVM ничего не ловят, поэтому на настоящем телефоне нужен проход руками.

## Как подготовиться

1. Телефон с Android 8+ (лучше 13+), установленная debug- или release-сборка.
2. Включить TalkBack: «Настройки → Специальные возможности → TalkBack». Жесты: свайп вправо/влево — следующий/предыдущий
   элемент, двойное касание — нажать.
3. Для каждого экрана ниже пройти свайпами все элементы подряд и отметить, что услышали.
4. Отдельно прогнать «Размер шрифта: максимальный» и «Размер элементов» (Настройки → Дисплей).

## Что слушать на каждом экране

Правило: ни одного «Кнопка» или «Изображение» без названия, ни одного «Снимите…» вместо смысла.

### Главная
- [ ] Приветствие читается как заголовок.
- [ ] Последнее измерение: «128 на 82 миллиметра ртутного столба», а не «128 слэш 82».
- [ ] Статус: «Статус: повышенное / в норме / пониженное» (слово, не только цвет).
- [ ] Карточка «7 дней» и карточка напоминания открываются двойным касанием.
- [ ] Кнопка «Записать давление» и круглая кнопка уровней названы.

### Ввод измерения
- [ ] Поля «Верхнее», «Нижнее», «Пульс» читаются с названием и значением; выбранное поле объявляется выбранным.
- [ ] Каждая цифра клавиатуры читается как «цифра 8», стирание и подтверждение названы.
- [ ] Ошибка проверки читается сразу, без поиска по экрану.
- [ ] Поле комментария называется «Свой комментарий» (проверить: до исправления шага 11.1 имени не было).
- [ ] Самочувствие читается как «флажок, выбран / не выбран».
- [ ] «Удалить» при правке и диалог подтверждения читаются.

### Дневник
- [ ] Заголовки дней («Сегодня», «Вчера», «18 октября, воскресенье») объявляются как заголовки.
- [ ] Строка читается целиком: время, значение, статус, пульс.
- [ ] Удаление: действие доступно не только свайпом (меню строки), кнопка «Отменить» в снэкбаре читается.
- [ ] Фильтр читается как группа переключателей с выбранным значением.

### Графики
- [ ] У графика есть текстовое описание периода и значений (формулировка ждёт заказчика).
- [ ] Переключатель 7/30 дней читается с выбранным значением.
- [ ] Сетка статистики читается по ячейкам («Среднее, 133 на 85»).

### Напоминания и их правка
- [ ] Переключатель читается как «Утреннее измерение, 08:00, включено».
- [ ] Баннер про уведомления: понятно, что делает кнопка «Разрешить».
- [ ] Выбор дней: чипы читаются как флажки («Пн, выбран»), пресеты как переключатели.
- [ ] Часовой циферблат Material читается и управляется (проверка самого виджета).
- [ ] Поле «Название» называется.

### Уровни
- [ ] Каждый степпер: «Повышенное, Верхнее (САД): увеличить / уменьшить»; недоступная кнопка объявляется недоступной.
- [ ] Пресеты читаются как переключатели; активный — выбран.
- [ ] Переключатель «Тёмная тема» назван.

### Настройки и «О приложении»
- [ ] Выбор темы читается как группа с выбранным значением.
- [ ] «Удалить все данные»: оба диалога читаются, фокус попадает в диалог, кнопка «Удалить навсегда» названа.
- [ ] «О приложении»: дисклеймер читается целиком.

### Онбординг и дисклеймер
- [ ] Индикатор шагов читается как «Шаг 1 из 3».
- [ ] Выбор уровней и переключатели напоминаний читаются как на основных экранах.
- [ ] Запрос уведомлений: системный диалог, затем возврат на экран; после отказа кнопка «Открыть настройки».
- [ ] Флажок дисклеймера читается; пока он не отмечен, «Продолжить» объявляется недоступной.

## Другие проверки из 10.6

- [ ] Контраст текста ≥ 4.5:1 во всех парах токенов Шалфея в обеих темах. Отчёт
      `core/designsystem/build/reports/contrast.txt` (после `:core:designsystem:test`): сейчас 16 пар светлых тем ниже 4.5,
      ждут решения дизайнера.
- [ ] `fontScale = 2.0`: нет обрезанного текста, карточки растут, клавиатура работает. Все основные экраны есть среди
      снимков с масштабом 2 (кроме Дневника в строках с очень длинным комментарием — проверить вручную).
- [ ] Инверсия цветов и «Высокий контраст текста» не делают текст невидимым.
- [ ] Навигация с внешней клавиатуры (Tab/Enter) проходит все действия экрана ввода.
- [ ] Альбомная ориентация: экран не ломается, нижняя навигация не закрывает контент.

## Известные ограничения (решить до релиза)

| # | Что | Где | Что делать |
|---|---|---|---|
| 1 | Часовой циферблат Material на масштабе шрифта 2× накладывает цифры друг на друга | Правка напоминания | Это сам виджет; можно переключить на ввод цифрами (`TimeInput`) при большом шрифте, решение за заказчиком |
| 2 | Диалоги Material берут сиреневый цвет по умолчанию, а не палитру приложения | Ввод, Настройки | Сопоставить `surfaceContainerHigh` в `core:designsystem`, нужен дизайнер |
| 3 | 16 пар контраста ниже 4.5 в светлых темах | Токены | Решение дизайнера |
| 4 | Чипы дней недели рисуются 42 dp шириной (высота 48) на экранах 360 dp; Compose расширяет область нажатия до 48 dp, области соседей перекрываются | Правка напоминания | Проверить пальцем на телефоне: не промахивается ли соседний день; при промахах сделать два ряда |
| 5 | Тексты описаний для TalkBack, помеченные PROVISIONAL (главная, дневник, графики, уровни, напоминания, онбординг, настройки) | `strings.xml` модулей | Подтвердить у заказчика |
