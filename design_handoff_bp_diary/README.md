# Handoff: Дневник давления (Android)

## Overview
Android-приложение для ведения дневника артериального давления: ввод измерений (САД/ДАД/пульс), дневник, графики и статистика, напоминания, пользовательские уровни высокого/низкого давления и пульса. Аудитория — 30–60 лет. Стиль — тёплый, мягкий, «заботливый». Светлая и тёмная тема.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы в HTML**: прототипы, показывающие внешний вид и поведение, а не продакшн-код. Задача — **воссоздать дизайн в целевой среде** (рекомендуется Kotlin + Jetpack Compose, Material 3) с её паттернами и библиотеками. Если кодовой базы нет — выбрать подходящий стек (Compose предпочтителен).

- `Дневник давления.dc.html` — холст с тремя направлениями (1a/1b/1c), каждое в светлой и тёмной теме.
- `BPApp.dc.html` — сам прототип: вся разметка (inline-стили) и логика (класс `Component` внизу файла: данные, классификация, графики). Открывается в браузере вместе с `support.js`.

## Fidelity
**High-fidelity.** Финальные цвета, шрифты, отступы, радиусы и взаимодействия. Воспроизводить точно. Направление (1a/1b/1c) выбирает заказчик; все три различаются только токенами (палитра, шрифт, радиус) — структура экранов одинаковая. Реализуйте токены как тему.

## Frame
Экран 360×780 dp. Статус-бар 34 dp. Нижняя навигация 74 dp (фон `sf2`) + жестовая полоса 22 dp. Контент между ними прокручивается. Горизонтальные поля экранов 20 dp (экран ввода — 16 dp).

## Interactions & Behavior
- Нижняя навигация (Главная `home`, Дневник `menu_book`, Графики `monitoring`, Напоминания `notifications`): активный пункт — pill 58×30 фона `acs`, подпись 700 `ink`; неактивные `mut`/500. На экранах «Ввод» и «Уровни» навигация скрыта.
- **Ввод с клавиатуры:** максимум 3 цифры на поле. Автопереход к следующему полю после 3 цифр или после 2 цифр, если первая цифра не «1» (95 → переход, 12… → ждём третью). Backspace на пустом поле переходит в предыдущее и стирает его последнюю цифру. Стрелка — следующее поле; галочка на «Пульс» — сохранить. Тап по полю делает его активным.
- **Сохранение:** запись добавляется наверх, поля, теги и комментарий сбрасываются, переход на Главную, тост «Измерение сохранено» (фон `ink`, текст `bg`, иконка `check_circle`, 2.4 с, над навигацией).
- **Рука:** последний выбор сохраняется (в прототипе — localStorage `bp-arm`; в продакшне — DataStore) и подставляется по умолчанию.
- **Классификация** (по пользовательским уровням): `hi`, если САД ≥ hs ИЛИ ДАД ≥ hd; иначе `lo`, если САД ≤ ls ИЛИ ДАД ≤ ld; иначе `ok`. Пульс вне [pl, ph] подсвечивается отдельно. При смене уровней всё пересчитывается сразу.

## State Management
- `readings[]`: { id, timestamp, sys, dia, pulse, arm: 'Левая'|'Правая', tags: string[], comment: string } — хранить в Room.
- `thresholds`: { hs, hd, ls, ld, pl, ph } — DataStore.
- `reminders[]`: { id, time 'HH:mm', label, days, enabled }.
- Настройки: theme (system/light/dark), lastArm.
- UI-состояние: экран, фильтр дневника, период графика, черновик ввода { sys, dia, pulse, activeField, tags, comment }.
- В прототипе есть сгенерированные демо-данные за 30 дней (2 измерения в день); «сейчас» зафиксировано на 20.10.2026 09:12.
